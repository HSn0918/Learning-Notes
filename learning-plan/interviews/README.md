## 概述

这个目录用于沉淀后续的面试材料。这里不按单场面试孤立保存，而是把每次面试中出现的问题归并到稳定的知识模块里，形成可持续扩展的题库和设计点清单。

处理一份新面试材料时，按下面顺序整理：

1. 提取面试中真实出现的问题。
2. 归入已有模块：项目架构、Operator、调度、GPU、K8s 基础、容错、业务场景、操作系统、网络基础、岗位判断。
3. 对每个问题补上：考察点、推荐回答、设计延伸、常见误区。
4. 如果出现新方向，再新增模块，不按公司或单次会议拆散。

## 模块化沉淀格式

每个模块里的题目使用同一结构：

```markdown

**考察点**：

**推荐回答**：

**设计延伸**：

**常见误区**：
```

这样后续新增面试材料时，只需要往已有模块追加题目或修正答案，不会变成一堆难以复用的流水记录。
